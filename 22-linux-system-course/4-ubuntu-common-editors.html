Часто используемые редакторы Ubuntu

4.1 Редакторы

4.1.1 vim

vim — это улучшенная версия vi. Наиболее заметное отличие заключается в том, что он может отображать некоторую специальную информацию системных файлов в разных цветах.

Команда установки

sudo apt install vim

Три основных режима

Командный режим (режим редактирования): режим по умолчанию, перемещение курсора, вырезание/вставка текста (индикация интерфейса: имя файла отображается в левом нижнем углу либо поле пустое).

Режим вставки (режим ввода): изменение текста (индикация интерфейса: в левом нижнем углу отображается -INSERT-). В режиме вставки нажатие клавиши ESC возвращает в командный режим.

Режим последней строки (расширенный режим): сохранение, выход и т. д. (индикация интерфейса: отображается -VISUAL-). В режиме последней строки два последовательных нажатия ESC возвращают в режим последней строки.

Переключение режимов

Переключение из командного режима в режим редактирования

i     # Режим вставки для перехода в режим редактирования
a     # Режим добавления (append) для перехода в режим редактирования
o     # Начать редактирование с начала следующей строки относительно текущей
O      # Начать редактирование с начала строки над текущей

Переключение из командного режима в режим последней строки

:     # Ввести двоеточие [:]

Переключение из режима последней строки в командный режим: нажать [esc]

Переключение из режима редактирования в командный режим: нажать [esc]

Esc: выход из текущего режима

Esc, затем ещё раз Esc: всегда возвращает в командный режим

Режим последней строки

w               # сохранить
q               # выйти
q!              # принудительный выход
x               # сохранить и выйти
set nu          # показать номера строк
set nonu        # скрыть номера строк
0,$d            # удалить всё содержимое файла в vim
/string         # искать строку string вперёд по тексту от курсора; n переходит к
следующему совпадению, shift+n — к предыдущему.
g/string         # найти строку string. Устанавливает курсор в начале первого
найденного совпадения строки string.

Командный режим

yy                 # копировать
p                  # вставить
3yy                # копировать 3 строки
2p                 # вставить 2 раза
dd                 # вырезать
3dd                # вырезать 3 строки
u                  # отменить
Ctrl + r           # отменить
dd                 # удалить текущую строку
dG                 # удалить от текущей строки до конца файла
dH                 # удалить от текущей строки до начала файла
gg                 # перейти к первой строке текущего документа
G                  # перейти к последней строке текущего документа
^                  # перейти к началу текущей строки
$                  # перейти к концу текущей строки
h                  # сдвиг на один символ влево
j                  # переместиться на строку вниз
k                  # переместиться на строку вверх
l                  # сдвиг на один символ вправо
PageDown (или Ctrl+F)           # прокрутить экран вниз
PageUp (или Ctrl+B)             # прокрутить экран вверх

4.1.2 nano

nano — текстовый редактор для Unix и Unix-подобных систем, форк редактора Pico.

Установка

sudo apt install nano

Создание/открытие файла

nano путь + имя_файла
Например: nano test_nano.txt

Управляющие команды

Ctrl+v       # Следующая страница
Ctrl+y       # Предыдущая страница
Ctrl+w       # Поиск слова или фразы
Ctrl+x       # Закрыть текущий текст, выйти из nano и вернуться в оболочку
Ctrl+\       # Поиск и замена
Ctrl+k       # Вырезать строки текста
Ctrl+u       # Вставить строки текста
Ctrl+c       # Показать позицию курсора в тексте

4.1.3 gedit

В этом редакторе можно нажать кнопку «Открыть», чтобы просмотреть список недавно открытых файлов и открыть файл; нажать кнопку «Сохранить», чтобы сохранить текущий редактируемый файл; нажать на меню справа, чтобы выполнить дополнительные операции.

Ctrl + s            сохранить файл
Ctrl + Shift + s           сохранить как
Ctrl + f          поиск текста

Редактор gedit можно запускать только при наличии графического интерфейса; его нельзя запустить удалённо без интерфейса, например через ssh, jupyter, putty и т. д.

Часто используемые команды Ubuntu

3.1 Добавление

Создание нового файла

touch test.txt

Создание новой папки

mkdir test # Создать папку
mkdir -p test/src # Создать папку test и внутри неё папку src

Копирование

sudo cp test.txt test_copy.txt # Скопировать файл

3.2 Удаление

-i        Выполнять в интерактивном режиме

-f        Принудительное удаление, игнорирует несуществующие файлы без предупреждения

-r        Рекурсивное удаление содержимого каталога

sudo rm test.txt         # Удалить файл | пустую папку
sudo rm -r test          # Удалить папку и её содержимое

3.3 Изменение

Перемещение и переименование

sudo mv test test_new                 # Переименовать папку test в test_new
sudo mv test.txt test_new.txt         # Переименовать файл test.txt в test_new.txt

chmod — изменение прав доступа к файлам

Настройка прав доступа

Символ Значение
+ Добавить права
- Отозвать права
= Установить права

rwx

Буква права Значение
r read — право на чтение. Для каталога отсутствие права r означает, что содержимое этого каталога нельзя просмотреть с помощью ls.
w write — право на запись. Для каталога отсутствие права w означает, что в каталоге нельзя создавать новые файлы.
x execute — право на выполнение. Для каталога отсутствие права x означает, что в каталог нельзя войти с помощью cd. 
sudo chmod +rwx test.txt

Быстрое добавление всех прав

sudo chmod 777 test.txt

Установка пароля root

sudo passwd root

Установка пароля пользователя

sudo passwd имя_пользователя

3.4 Просмотр

Просмотр версии системы

lsb_release -a        # Номер версии релиза
uname -a              # Версия ядра и разрядность системы
cat /proc/version # Версия ядра и версия gcc

Просмотр информации об оборудовании

curl cip.cc or ifconfig                # Просмотр IP-адреса
cat /proc/cpuinfo or lscpu             # Информация о процессоре
sudo dmidecode -t memory               # Информация об оперативной памяти
df -h                                  # Просмотр состояния занятого места на всех
подключённых файловых системах
which python3                          # Просмотр расположения команды
v4l2-ctl --list-formats-ext            # Просмотр параметров устройства камеры
nproc          # Проверка количества ядер

Просмотр информации о файлах

la            # Отображает все подкаталоги и файлы в указанном каталоге,
включая скрытые файлы
ll            # Отображает подробную информацию о файлах в виде списка
ls -h         # Используется для отображения размера файла в удобном для пользователя виде
cat test.txt          # Просмотр содержимого файла
tree                  # Просмотр дерева каталогов (требуется установка tree)

Команда установки tree

sudo apt install tree

Поиск файлов

find ./ -name test.sh         # Найти все файлы или каталоги с именем test.sh в
текущем каталоге
find ./ -name '*.sh'          # Найти все файлы или каталоги с расширением .sh в
текущем каталоге
find ./ -name "[A-Z]*"        # Найти все файлы или каталоги, имя которых начинается
с прописной буквы, в текущем каталоге

3.5 Прочее

Команда tar

Формат использования tar: tar [параметр] имя_архива файл

-c      # Создать архив, упаковать файлы
-v      # Показывать подробный процесс архивирования/разархивирования и отображать
прогресс
-f      # Указать имя архивного файла. После f обязательно должно следовать имя файла
.tar, поэтому этот параметр нужно указывать последним.
-t      # Вывести список файлов, содержащихся в архиве
-x      # Распаковать архив

Упаковка

tar -cvf xxx.tar *                        # Все файлы в текущем каталоге
tar -cvf xxx.tar *.txt                    # Файлы с расширением .txt
tar -cvf xxx.tar my-file my-dir           # Упаковать указанный каталог или файл

Распаковка

tar -xvf xxx.tar                    # Распаковать в текущий каталог
tar -xvf xxx.tar -C my-dir          # Распаковать в указанный каталог (каталог
my-dir нужно создать заранее)

Команды zip и unzip

Сжатие файла: zip [-r] имя_архива (без расширения) исходный_файл

zip bak *           # Все файлы в текущем каталоге, можно также указать конкретные файлы
zip -r bak *        # Все файлы и каталоги в текущем каталоге рекурсивно

Распаковка файла: unzip -d каталог файл после распаковки сжатого файла

unzip -d ./target_dir bak.zip            # Распаковать в указанный каталог
unzip bak.zip                            # Распаковать в текущий каталог

Команда ln

Символическая (мягкая) ссылка: символическая ссылка не занимает места на диске. Если исходный файл удалён, символическая ссылка становится недействительной. Часто используется, можно создавать ссылки как на файлы, так и на папки.

ln -s Исходный_файл            Файл_ссылки

Жёсткие ссылки: жёсткие ссылки можно создавать только для обычных файлов, но не для каталогов. Даже если исходный файл удалён, файл, на который ведёт ссылка, продолжает существовать.

ln Исходный_файл         Файл_ссылки

Удалённое копирование scp

scp jetson@192.168.16.66:/home/jetson/xxx.tar.gz /home/yahboom/ # Копирование файла
с удалённой машины на локальную
scp /home/yahboom/xxx.png jetson@192.168.16.66:/home/jetson/                     # Копирование файла
с локальной машины на удалённую
scp -r jetson@192.168.16.66:/home/jetson/test /home/yahboom/                     # Копирование каталога
с удалённой машины на локальную -r
scp -r /home/yahboom/test jetson@192.168.16.66:/home/jetson/                     # Копирование каталога
с локальной машины на удалённую -r

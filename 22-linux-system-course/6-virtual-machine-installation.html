Установка виртуальной машины

Имя пользователя: yahboom

Пароль: yahboom

Пароль виртуальной машины: Ubuntu20.04

1.1 Установка виртуальной машины

Виртуальная машина VMware Workstation — платное программное обеспечение, и мы не предоставляем дистрибутив VMware для скачивания. Вам нужно скачать его самостоятельно из интернета, а затем дважды щёлкнуть по скачанному установочному файлу exe.

Нажмите «Далее».

Отметьте флажок принятия лицензии и нажмите «Далее».

Выберите место установки, отметьте пункт «Добавить инструменты консоли в систему» и нажмите «Далее».

Продолжайте нажимать «Далее», пока не откроется следующий экран.

Нажмите «Установить» и подождите несколько минут.

Вышеописанное завершает установку VMWare. Теперь можно открыть VMWare на рабочем столе, как показано ниже.

1.2 Использование виртуальной машины

Найдите локальный жёсткий диск, на котором осталось более 40 ГБ свободного места, и распакуйте архив с системой.

После установки виртуальной машины VMware Workstation дважды щёлкните, чтобы открыть её, и перейдите на экран, показанный на рисунке. Нажмите [Open Virtual Machine] («Открыть виртуальную машину»).

Выберите распакованный файл системы, как показано на рисунке ниже.

Нажмите [Start this virtual machine] («Запустить эту виртуальную машину»).

Если появится подсказка, показанная на рисунке ниже, сразу выберите [I have copied this virtual machine (p)] («Я скопировал эту виртуальную машину»).

Нажмите [yahboom].

Введите пароль [yahboom] и нажмите клавишу [Enter] на клавиатуре для подтверждения.

1.3 Настройки виртуальной машины

Настройки виртуальной машины можно изменить перед её запуском — как показано ниже, нажмите [Edit Virtual Machine Settings] («Изменить настройки виртуальной машины»).

Откроется диалоговое окно [Virtual Machine Settings] («Настройки виртуальной машины»).

Поскольку конфигурация каждого компьютера отличается, настройки можно задавать в соответствии с реальной ситуацией. Чем выше объём выделенной оперативной памяти виртуальной машины, тем быстрее она будет работать, но не следует превышать максимально доступный объём памяти.

Процессор: чем больше количество ядер (c) на процессор, тем более плавно будет работать виртуальная машина, но их число не должно превышать общее количество доступных ядер.

USB-контроллер: совместимость USB установлена на [USB 3.1], чтобы можно было использовать устройства USB 3.0.

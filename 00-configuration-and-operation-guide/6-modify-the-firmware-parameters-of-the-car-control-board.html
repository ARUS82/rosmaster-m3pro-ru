Изменение параметров прошивки платы управления машиной

Для выполнения этого урока необходимо, чтобы в машину была предварительно прошита заводская прошивка, — только тогда можно настраивать параметры прошивки. Изменение параметров прошивки платы управления позволяет настроить поведение машины в соответствии с личными потребностями. Заводская прошивка поставляется со значениями по умолчанию, и их можно не менять, если это не требуется.

На плату управления машины предварительно прошита заводская прошивка. Если была прошита другая прошивка, выполните действия из урока [12. Курс по плате управления\1. Настройка среды разработки для платы управления\4. Прошивка STM32 через последовательный порт], чтобы заново прошить заводскую прошивку. Заводская прошивка находится в документе [Приложение\Заводская прошивка платы управления].

В этом уроке в качестве примера рассматривается материнская плата серии Jetson Orin; для остальных материнских плат действия аналогичны.

Примечание: перед запуском скрипта изменения конфигурации необходимо сначала остановить агент micro-ROS.

1. Подключение оборудования

Убедитесь, что порт Type-C USB на плате управления подключён к USB-порту материнской платы.

2. Изменение параметров

Откройте системный терминал, найдите и откройте файл [config_robot.py] в домашнем каталоге пользователя.

vim ~/config_robot.py

Перейдите в конец файла — там находятся параметры конфигурации: set_ros_domain_id, set_ros_namespace, set_motor_pid_parm, set_imu_yaw_pid_parm, set_ros_scale_line, set_ros_scale_angular и set_arm_mid_value.

Если нужно изменить какой-либо параметр, снимите символ комментария перед соответствующей функцией.

# robot.set_ros_domain_id(30)
# robot.set_ros_namespace("")
# robot.set_motor_pid_parm(0.8, 0.06, 0.5)
# robot.set_imu_yaw_pid_parm(0.6, 0, 0.3)

# robot.set_ros_scale_line(1.0)
# robot.set_ros_scale_angular(1.0)

# arm_mid_value = [2000, 2000, 2000, 2000, 1486, 3100]
# robot.set_arm_mid_value(arm_mid_value)

Здесь set_ros_domain_id задаёт ROS DOMAIN ID машины — значение в диапазоне от 0 до 100. Если в локальной сети присутствует несколько устройств, каждому из них следует задать свой ROS_DOMAIN_ID, чтобы избежать взаимных помех. Обратите внимание: значение ROS_DOMAIN_ID должно совпадать со значением в файле .bashrc системного терминала, чтобы обеспечить связь.

set_ros_namespace задаёт пространство имён (namespace) ROS машины — используется в основном для функции управления несколькими машинами в одной локальной сети.

set_motor_pid_parm задаёт ПИД-параметры скорости моторов машины.

set_imu_yaw_pid_parm задаёт ПИД-параметры, используемые для калибровки направления машины по данным IMU.

set_ros_scale_line задаёт коэффициент масштабирования линейной скорости ROS машины.

set_ros_scale_angular задаёт коэффициент масштабирования угловой скорости ROS машины.

Функция set_arm_mid_value задаёт смещение среднего значения манипулятора. Используется в основном для быстрого восстановления значения калибровки манипулятора и, как правило, не требует изменения. Примечание: изменение этого значения повлияет на калибровочное значение манипулятора. Если требуется калибровка манипулятора, обратитесь к уроку по калибровке манипулятора.

3. Запись конфигурации

Примечание: перед запуском скрипта изменения конфигурации необходимо сначала остановить агент micro-ROS.

Откройте системный терминал и выполните следующую команду, чтобы начать запись конфигурации

python3 ~/config_robot.py

Вы увидите все итоговые значения параметров, считанные после записи.

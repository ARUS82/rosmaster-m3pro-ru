16. Общие инструменты командной строки ROS2

1. Инструмент управления пакетами ros2 pkg

1.1. ros2 pkg create

Назначение: создаёт пакет. При создании пакета необходимо указать имя пакета, метод компиляции, зависимости и т.д.

Формат:

ros2 pkg create <package_name> --build-type <build-type> --dependencies
<dependencies>

В команде ros2:

  • pkg: указывает на функции, связанные с пакетом;
  • create: указывает на создание пакета;
  • package_name: обязательный параметр — имя нового пакета;
  • build-type: обязательный параметр — указывает, является ли создаваемый пакет пакетом на C++ или Python. При использовании C++ или C следует указывать ament_cmake; при использовании Python — ament_python;
  • dependencies: необязательный параметр — указывает зависимости пакета. Пакеты на C++ должны включать rclcpp; пакеты на Python должны включать rclpy, а также другие необходимые зависимости.

1.2. ros2 pkg list

Назначение: просмотр списка пакетов в системе

Формат:

ros2 pkg list

1.3. ros2 pkg executables

Назначение: просмотр всех исполняемых файлов в пакете

Формат:

ros2 pkg executables pkg_name

2. Запуск ноды ros2 run

Назначение: запуск программы-ноды в пакете

Формат:

ros2 run pkg_name node_name
  • pkg_name: имя пакета
  • node_name: имя исполняемой программы

3. Инструменты, связанные с нодами: ros2 node

3.1. ros2 node list

Назначение: выводит список всех имён нод в текущем домене

Формат:

ros2 node list

3.2. ros2 node info

Назначение: просмотр подробной информации о ноде, включая подписки, публикуемые сообщения, включённые сервисы и действия (actions).

Формат:

ros2 node info node_name
  • node_name: имя ноды, которую нужно просмотреть.

4. Инструменты, связанные с топиками: ros2 topic

4.1. ros2 topic list

Назначение: вывод списка всех топиков в текущем домене

Формат:

ros2 topic list

4.2. ros2 topic info

Назначение: отображение типа сообщения топика и количества подписчиков/издателей

Формат:

ros2 topic info topic_name
  • topic_name: имя запрашиваемого топика.

4.3. ros2 topic type

Назначение: просмотр типа сообщения топика

Формат:

ros2 topic type topic_name
  • topic_name: имя топика, тип которого требуется узнать.

4.4. ros2 topic hz

Назначение: отображение средней частоты публикации топика.

Формат:

ros2 topic hz topic_name
  • topic_name: имя топика, частоту которого нужно узнать.

4.5. ros2 topic echo

Назначение: вывод сообщений топика в терминал, аналогично подписчику.

Формат: ros2 topic echo topic_name

  • topic_name: имя топика, сообщения которого нужно выводить.

4.5. ros2 topic pub

Назначение: публикация сообщения в указанном топике из терминала.

Формат:

ros2 topic pub topic_name message_type message_content
  • topic_name: имя топика, в который нужно публиковать сообщения.
  • message_type: тип данных топика.
  • message_content: содержимое сообщения

По умолчанию публикация происходит с частотой 1 Гц. Можно задать следующие параметры:

  • Параметр -1 для однократной публикации: ros2 topic pub -1 topic_name message_type message_content
  • Параметр -t count для публикации count раз: ros2 topic pub -t count topic_name message_type message_content
  • Параметр -r count для публикации с частотой count Гц: ros2 topic pub -r count topic_name message_type message_content

Пример:

  • Публикация команд скорости через командную строку
  • Обратите внимание, что после каждого двоеточия должен быть пробел, иначе будет отображена ошибка формата.
ros2 topic pub turtle1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.5, y: 0.0,
z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.2}}"

5. Инструменты, связанные с интерфейсами: ros2 interface

5.1. ros2 interface list

Назначение: вывод списка всех интерфейсов в текущей системе, включая топики, сервисы и действия (actions).

Формат:

ros2 interface list

5.2. ros2 interface show

Назначение: отображение подробной информации об указанном интерфейсе

Формат:

ros2 interface show interface_name
  • interface_name: имя интерфейса, который требуется отобразить

6. Инструменты, связанные с сервисами: ros2 service

6.1. ros2 service list

Назначение: вывод списка всех сервисов в текущем домене

Формат:

ros2 interface show interface_name

6.2. ros2 service call

Назначение: вызов указанного сервиса

Формат:

ros2 interface call service_name service_Type arguments
  • service_name: сервис, который нужно вызвать
  • service_type: тип данных сервиса
  • arguments: параметры, необходимые для выполнения сервиса

Например, вызов сервиса создания черепахи (spawn)

ros2 service call /spawn turtlesim/srv/Spawn "{x: 2, y: 2, theta: 0.2, name:
'turtle10'}"

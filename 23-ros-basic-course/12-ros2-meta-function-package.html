Метапакеты ROS2

1. Введение в метапакеты

Реализация системной функции может включать несколько пакетов. Например, реализация модуля навигации робота может включать такие подпакеты, как построение карты, локализация и планирование пути. Так нужно ли пользователю устанавливать каждый пакет по отдельности при установке этого модуля?

Очевидно, что устанавливать пакеты по одному неэффективно. ROS2 предоставляет способ объединения различных пакетов в единый пакет. При установке модуля можно напрямую вызвать такой объединённый пакет, также называемый метапакетом (metapackage).

Метапакет — это концепция системы управления файлами в Linux. В ROS2 это виртуальный пакет. Он не содержит содержательного кода, но зависит от других пакетов. Этот способ позволяет группировать пакеты вместе. Представьте его как таблицу содержания в книге, которая говорит вам, какие подпакеты находятся внутри пакета и откуда их скачать.

Например, команда "sudo apt install ros-humle-desktop" устанавливает ROS2 с помощью метапакета. Этот метапакет зависит от нескольких других пакетов ROS2, и эти зависимости устанавливаются вместе с пакетом.

Классический пример метапакета: navigation2

  • Репозиторий navigation2 на GitHub: GitHub - ros-navigation/navigation2: ROS 2 Navigation Framework and System

2. Назначение

Этот пакет облегчает установку. Нам нужен только этот один пакет, чтобы организовать и установить другие связанные пакеты.

3. Реализация

  1. Создайте новый пакет
ros2 pkg create pkg_metapackage
  1. Измените файл package.xml и добавьте пакеты, от которых зависит выполнение
<?xml version="1.0"?>
<?xml-model href="http://download.ros.org/schema/package_format3.xsd"
schematypens="http://www.w3.org/2001/XMLSchema"?>
<package format="3">
  <name>pkg_metapackage</name>
  <version>0.0.0</version>
  <description>TODO: Package description</description>
  <maintainer email="1461190907@qq.com">root</maintainer>
  <license>TODO: License declaration</license>

  <buildtool_depend>ament_cmake</buildtool_depend>
  1. Содержимое файла CMakeLists.txt следующее
<exec_depend>pkg_interfaces</exec_depend>
<exec_depend>pkg_helloworld_py</exec_depend>
<exec_depend>pkg_topic</exec_depend>
<exec_depend>pkg_service</exec_depend>
<exec_depend>pkg_action</exec_depend>
<exec_depend>pkg_param</exec_depend>

<test_depend>ament_lint_auto</test_depend>
<test_depend>ament_lint_common</test_depend>

<export>
   <build_type>ament_cmake</build_type>
</export>
</package>

cmake_minimum_required(VERSION 3.5)
project(pkg_metapackage)

if(CMAKE_COMPILER_IS_GNUCXX OR CMAKE_CXX_COMPILER_ID MATCHES "Clang")
add_compile_options(-Wall -Wextra -Wpedantic)
endif()

find_package(ament_cmake REQUIRED)

ament_package()

  1. Компиляция метапакета

Реальных исполняемых файлов не будет создано.

colcon build --packages-select pkg_metapackage

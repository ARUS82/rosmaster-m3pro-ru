Пользовательские интерфейсные сообщения ROS2

1. Введение в интерфейсы взаимодействия

В системе ROS, будь то топики, сервисы или экшны, используется ключевое понятие: интерфейс взаимодействия (communication interface).

Взаимодействие — это не разговор с самим собой, это обмен между двумя или более сторонами. Что представляет собой содержание этого взаимодействия? Чтобы всем было проще понять, мы можем определить стандартную структуру для передаваемых данных. Это и есть интерфейс взаимодействия.

Интерфейсы уменьшают зависимости между программами, облегчая использование чужого кода нам и использование нашего кода другими. Это основная цель ROS: снизить необходимость изобретать колесо заново.

В ROS есть три распространённых механизма взаимодействия: топики, сервисы и экшны. Через интерфейсы, определённые для каждого типа взаимодействия, различные узлы органично соединяются друг с другом.

2. Процесс создания пользовательского интерфейса

Процесс создания пользовательских интерфейсных сообщений похож на написание исполняемой программы в пакете. Основные шаги следующие:

  1. Создать пакет интерфейса;
  2. Создать и отредактировать файлы .msg, .srv и .action;
  3. Отредактировать конфигурационный файл;
  4. Скомпилировать;
  5. Протестировать.

3. Создание пользовательского интерфейса экшн-взаимодействия

В примере [11. ROS2 Action Communication Server Implementation] мы продемонстрировали полный процесс создания интерфейса экшн-взаимодействия. Вы можете сначала просмотреть его; здесь мы не будем повторяться.

4. Создание пользовательского интерфейса для топик-взаимодействия

  1. В курсе [ROS2 Action Communication Server Implementation] мы создали пакет пользовательского интерфейса. Создайте папку msg в пакете pkg_interfaces и файл Person.msg в папке msg. Введите в файле следующее содержимое:
string name
int32 age
float64 height

  1. Добавьте следующую конфигурацию в package.xml и CMakeLists.txt:

CMakeLists.txt

rosidl_generate_interfaces(${PROJECT_NAME}
"action/Progress.action"
"msg/Person.msg"
)

package.xml

<buildtool_depend>rosidl_default_generators</buildtool_depend>
<exec_depend>rosidl_default_runtime</exec_depend>
<depend>action_msgs</depend>
<member_of_group>rosidl_interface_packages</member_of_group>
  1. Перейдите в текущее рабочее пространство в терминале и скомпилируйте пакет:
colcon build --packages-select pkg_interfaces
  1. Проверьте, что интерфейс работает корректно.

Сначала обновите переменные окружения.

source install/setup.bash

Проверьте тип интерфейса:

ros2 interface show pkg_interfaces/msg/Person

В обычной ситуации вывод в терминале будет совпадать с содержимым файла Person.msg.

5. Создание пользовательского интерфейса сервис-взаимодействия

  1. В курсе [ROS2 Action Communication Server Implementation] мы создали пакет пользовательского интерфейса. Создайте новую папку srv в пакете pkg_interfaces. Создайте новый файл Add.srv в папке srv и введите в файле следующее содержимое:
int32 num1
int32 num2
---
int32 sum

  1. Добавьте следующую конфигурацию в package.xml и CMakeLists.txt:

CMakeLists.txt

rosidl_generate_interfaces(${PROJECT_NAME}
    "action/Progress.action"
    "msg/Person.msg"
    "srv/Add.srv"
)

package.xml

<buildtool_depend>rosidl_default_generators</buildtool_depend>
<exec_depend>rosidl_default_runtime</exec_depend>
<depend>action_msgs</depend>
<member_of_group>rosidl_interface_packages</member_of_group>
  1. Перейдите в текущее рабочее пространство в терминале и скомпилируйте пакет:
cd ~/yahboomcar_ros2_ws/yahboomcar_ws
colcon build --packages-select pkg_interfaces
source install/setup.bash
  1. Тестирование
ros2 interface show pkg_interfaces/srv/Add

В обычной ситуации терминал выведет то же содержимое, что и файл Person.msg.

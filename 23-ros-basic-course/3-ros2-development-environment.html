Среда разработки ROS2

В теории писать простые программы для ROS2 можно и в Notepad, но для повышения эффективности разработки стоит установить интегрированную среду разработки (VSCode).

1. Использование среды разработки VSCode

Найдите в браузере "VSCode", выберите установочный пакет для своей платформы, скачайте и установите его.

Установите часто используемые плагины для повышения эффективности работы.

2. Использование терминала

В ROS2 вы будете часто использовать терминал. Мы рекомендуем достаточно удобный терминал: Terminator. Результат выглядит так:

2.1. Установка

sudo apt install terminator

2.2. Запуск

Сочетание клавиш Ctrl+Alt+T для запуска.

3. Использование Git

3.1. Установка

Поскольку повседневная работа связана с командной работой и управлением версиями, Git — необходимый навык. Git — это свободная и open source распределённая система контроля версий. Для установки Git в Ubuntu:

sudo apt install git

3.2. Основные операции Git

Задача Git — создавать и сохранять снимки (snapshots) вашего проекта и сравнивать их с последующими снимками.

В этой главе рассматриваются команды для создания и коммита снимков вашего проекта.

Git использует следующие шесть команд: git clone, git push, git add, git commit, git checkout и git pull. Подробнее о них мы расскажем далее.

Описание:

  • workspace: рабочая директория (Workspace)
  • staging area: индекс/область подготовки (Staging area)
  • local repository: репозиторий или локальный репозиторий
  • remote repository: удалённый репозиторий

Простое пошаговое руководство:

$ git init
$ git add .
$ git commit
  • git init - инициализирует репозиторий.
  • git add . - добавляет файлы в область подготовки (staging area).
  • git commit - переносит содержимое области подготовки в репозиторий.

3.2.1. Команды создания репозитория

В таблице ниже перечислены команды Git для создания репозиториев:

Команда Описание
git init Инициализирует репозиторий
git clone Создаёт копию удалённого репозитория, по сути — скачивает проект

3.2.2. Коммит и изменение

Задача Git — создавать и сохранять снимки вашего проекта и сравнивать их с последующими снимками.

В таблице ниже перечислены команды для создания и коммита снимков вашего проекта:

Команда Описание
git add Добавляет файлы в область подготовки
git status Показывает текущий статус репозитория, отображая изменённые файлы
git diff Сравнивает различия между файлами, то есть различия между областью подготовки и рабочей директорией
git commit Переносит содержимое области подготовки в локальный репозиторий
git reset Откатывает изменения к предыдущей версии
git rm Удаляет файл из области подготовки и рабочей директории
git mv Перемещает или переименовывает файл в рабочей директории
git checkout Переключает ветки
git switch (появилась в Git 2.23) Более "чистое" переключение веток
git restore (появилась в Git 2.23) Отменяет изменения файла

3.2.3. Журнал коммитов

Команда Описание
git log Просмотр истории коммитов
git blame Просмотр истории изменений указанного файла в виде списка

3.2.4. Операции с удалённым репозиторием

Команда Описание
git remote Операции с удалённым репозиторием
git fetch Получить код из удалённого репозитория
git pull Скачать и слить код из удалённого репозитория
git push Отправить и слить код в удалённый репозиторий

Для получения дополнительной информации об использовании инструмента Git введите в терминале git --help, чтобы открыть справочную документацию.

Сервис-взаимодействие в ROS2

1. Введение в сервис-взаимодействие

Сервис-взаимодействие (service communication) — это модель взаимодействия по принципу запрос-ответ. На двух концах цепочки взаимодействия клиент отправляет запрос серверу, а сервер отвечает клиенту.

Модель клиент/сервер выглядит так:

С точки зрения реализации сервиса, такой формат вопрос-ответ называется моделью клиент/сервер, или сокращённо CS-моделью. Когда клиенту нужны определённые данные, он отправляет запрос конкретному сервису. После получения запроса сервер обрабатывает его и возвращает ответ.

Этот механизм взаимодействия также очень распространён в повседневной жизни. Например, при просмотре различных веб-страниц ваш браузер является клиентом. Он отправляет запрос к серверу сайта с использованием доменного имени и различных операций. Сервер затем отвечает данными страницы, которые нужно отобразить.

2. Создание нового пакета

В директории src рабочего пространства:

ros2 pkg create pkg_service --build-type ament_python --dependencies rclpy --node-name server_demo

После выполнения указанной команды будет создан пакет pkg_service, а также узел server_demo и соответствующие конфигурационные файлы.

3. Реализация сервера

3.1 Создание сервера

Далее отредактируйте [server_demo.py], чтобы реализовать функциональность сервера, и добавьте следующий код:

#Import related libraries
import rclpy
from rclpy.node import Node
from example_interfaces.srv import AddTwoInts


class Service_Server(Node):
     def __init__(self,name):
         super().__init__(name)
         #Create a server using the create_service function. The parameters
passed in are:
         #Service data type, service name, service callback function (i.e.,
service content)
         self.srv = self.create_service(AddTwoInts, '/add_two_ints',
self.Add2Ints_callback)
     #The service callback function here adds two integers and returns the result.


     def Add2Ints_callback(self,request,response):
         response.sum = request.a + request.b
         print("response.sum = ",response.sum)
         return response
def main():
     rclpy.init()
     server_demo = Service_Server("publisher_node")
     rclpy.spin(server_demo)
     server_demo.destroy_node()                              #Destroy the node object
     rclpy.shutdown()                                        #Shut down the ROS2 Python
interface

Обратите внимание на функцию обратного вызова сервиса, Add2Ints_callback. Помимо self, здесь требуются параметры request и response. Request — это параметр, требуемый сервисом, а response — обратная связь сервиса. Request.a и request.b — содержимое запроса, а response.sum — содержимое ответа. Сначала посмотрим, как выглядит тип данных AddTwoInts.

Вы можете использовать следующую команду, чтобы просмотреть его:

ros2 interface show example_interfaces/srv/AddTwoInts

Символ "---" делит тип данных на две части: верхняя часть представляет запрос, а нижняя — ответ. Каждое поле содержит свою переменную, например int64 a и int64 b. При передаче параметров необходимо указать значения a и b. Аналогично, в результате обратной связи также нужно указать значение sum.

3.2 Редактирование конфигурационного файла

Откройте setup.py и добавьте следующую строку в список console_scripts:

'server_demo = pkg_service.server_demo:main',

3.3 Компиляция пакета

Компиляция пакета:

colcon build --packages-select pkg_service

3.4 Запуск программы

Обновите переменные окружения и запустите узел.

ros2 run pkg_service server_demo

После запуска, поскольку сервис не вызывается, обратной связи нет. Вы можете вызвать сервис через командную строку. Сначала запросите список текущих сервисов. В другом терминале введите:

ros2 service list

/add_two_ints — сервис, который нам нужно вызвать. Вызовите его следующей командой. В терминале введите:

ros2 service call /add_two_ints example_interfaces/srv/AddTwoInts "{a: 1, b: 4}"

Здесь мы присваиваем значению a значение 1, а значению b значение 4, тем самым вызывая сервис для вычисления суммы 1 и 4:

Как показано на изображении выше, после вызова сервиса возвращённый результат равен 5, и терминал, в котором запущен сервер, также выводит возвращённое значение.

4. Реализация клиента

4.1 Создание клиента

Создайте новый файл, [client_demo.py], в той же директории, что и [server_demo.py].

Далее отредактируйте [client_demo.py], чтобы реализовать функциональность клиента, и добавьте следующий код:

#Import related libraries
import rclpy
from rclpy.node import Node
from example_interfaces.srv import AddTwoInts


class Service_Client(Node):
    def __init__(self,name):
         super().__init__(name)
         #Create the client using the create_client function, passing in the
service data type and service topic name as parameters.
         self.client = self.create_client(AddTwoInts,'/add_two_ints')
         #Loop waiting for the server to successfully start
         while not self.client.wait_for_service(timeout_sec=1.0):
              print("service not available, waiting again...")
         #Create the service request data object
         self.request = AddTwoInts.Request()


    def send_request(self):
         self.request.a = 10
         self.request.b = 90
         #Send the service request
         self.future = self.client.call_async(self.request)


def main():
    rclpy.init() #Node initialization
    service_client = Service_Client("client_node") #Create object
    service_client.send_request() #Send service request
    while rclpy.ok():
         rclpy.spin_once(service_client)
         #Determine if data processing is complete
         if service_client.future.done():
               try:
                   #Get service feedback and print it
                   response = service_client.future.result()
                   print("service_client.request.a = ",service_client.request.a)
                   print("service_client.request.b = ",service_client.request.b)
                   print("Result = ",response.sum)
              except Exception as e:
                   service_client.get_logger().info('Service call failed %r' %
(e,))
         break
    service_client.destroy_node()
    rclpy.shutdown()

4.2 Редактирование конфигурационного файла

Откройте setup.py и добавьте следующую строку в список console_scripts:

'client_demo = pkg_service.client_demo:main'

4.3 Компиляция пакета

colcon build --packages-select pkg_service

4.4 Запуск программы

Обновите переменные окружения и запустите узел:

# Start the server node
ros2 run pkg_service server_demo
# Start the client node
ros2 run pkg_service client_demo

Сначала запустите сервер, затем клиент. Клиент передаёт a=10 и b=90. Сервер выполняет сложение и получает 100. Результат выводится в обоих терминалах.

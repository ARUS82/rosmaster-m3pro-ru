Транспортировка по машинному коду (AprilTag)

1. Описание содержания

В этом разделе объясняется, как объединить навигацию nav2, распознавание машинного кода (AprilTag) и трёхмерный захват манипулятором для реализации сложной функции транспортировки объектов.

В этом разделе команды вводятся в терминале. Какой терминал открывать, зависит от типа используемой материнской платы. В этом разделе в качестве примера используется Raspberry Pi 5. Для материнских плат Raspberry Pi и Jetson-Nano необходимо открыть терминал на хост-компьютере и ввести команду для входа в Docker-контейнер. После входа в контейнер вводите команды этого раздела уже внутри него. Инструкции по входу в Docker-контейнер с хост-компьютера см. в руководстве к изделию [Configuration and Operation Guide] — [Entering the Docker] (для пользователей Jetson-Nano и Raspberry Pi 5, см. соответствующий раздел).

Для плат Orin достаточно просто открыть терминал и ввести команды этого раздела.

2. Запуск программы

Виртуальная машина должна находиться в одной локальной сети с роботом, и значение ROS_DOMAIN_ID должно совпадать на обоих устройствах. Измените значение ROS_DOMAIN_ID в файле ~/.bashrc и обновите переменные окружения после изменения.

Введите следующую команду в терминале 1 робота, чтобы запустить программу камеры и решение кинематики манипулятора:

ros2 launch M3Pro_demo camera_arm_kin.launch.py

Введите следующую команду в терминале 2 робота, чтобы запустить программу слияния данных шасси и фильтрации объединённых данных лидара:

ros2 launch M3Pro_navigation base_bringup.launch.py

Введите следующую команду в терминале 3 робота, чтобы запустить программу захвата:

ros2 run M3Pro_demo grasp_transport

Введите следующую команду в терминале 4 робота, чтобы запустить программу распознавания машинного кода:

ros2 run M3Pro_demo apriltag_transport_V2

Введите команду в терминале 1 виртуальной машины, чтобы запустить отображение навигации в rviz.

ros2 launch slam_view slam_view.launch.py

Введите следующую команду в терминале 5 робота, чтобы запустить navigation2:

ros2 launch M3Pro_navigation navigation2.launch.py map_dir:= /root/M3Pro_ws/src/yahboom_mapping/maps/yahboom_map.yaml

Здесь /root/M3Pro_ws/src/yahboom_mapping/maps/yahboom_map.yaml замените на путь к файлу вашей собственной карты в формате yaml.

Введите следующую команду в терминале 2 виртуальной машины, чтобы запустить программу обнаружения поворота:

ros2 run yahboom_nav2_bringup rotation_detect_V2

Введите следующую команду в терминале 3 виртуальной машины, чтобы запустить программу проверки статуса навигации:

ros2 run yahboom_nav2_bringup get_nav2_status_V2

После запуска в rviz на виртуальной машине с помощью инструмента [2D Pose Estimate] задайте роботу начальное положение, исходя из его фактического положения в пространстве и на карте. Убедитесь, что препятствия, отсканированные лидаром робота, совпадают с чёрными областями на карте, как показано на рисунке ниже.

Затем нажмите [Waypoint/Nav Through Poses Mode] в [Navigation2 navigation plug-in] и выберите его, как показано ниже.

Затем с помощью инструмента [Nav2 Goal] задайте целевую точку. Робот автономно выполнит навигацию к этой точке. По достижении цели сработает звуковой сигнализатор робота.

Можно нажимать клавиши n, r или b, чтобы выбрать следующие режимы:

  • Нажатие клавиши n: выбор режима навигации, затем с помощью инструмента [Nav2 Goal] задайте целевую точку. Робот выполнит навигацию к этой точке и подаст звуковой сигнал по достижении цели.

  • Нажатие клавиши r: выбор режима поворота — робот совершает полный оборот, как показано на рисунке ниже. Во время поворота:

  • Если робот обнаруживает деревянный блок с машинным кодом, он останавливает вращение, а затем перемещается влево и вправо, чтобы скорректировать горизонтальное расстояние до машинного кода. После корректировки он перемещается вперёд и назад, чтобы скорректировать продольное расстояние до машинного кода. После корректировки нижний захват захватывает блок с машинным кодом.

  • После захвата срабатывает звуковой сигнализатор, и манипулятор перемещается в положение для транспортировки.
  • Наконец, по подсказке терминала: нажмите клавишу b, чтобы вернуться навигацией к исходной точке (начальному положению), после чего нижний захват отпустит деревянный блок с машинным кодом. Либо можно напрямую использовать инструмент [Nav2 Goal], чтобы задать целевую точку. После того как робот выполнит навигацию к этой точке, нижний захват отпустит блок с машинным кодом.
  • Если машинный код не обнаружен, терминал робота предложит нажать клавишу n и с помощью инструмента [Nav2 Goal] задать целевую точку. Робот перейдёт к следующей целевой точке, либо нажмите клавишу b, чтобы вернуться к исходной точке (начальному положению).
  • Нажатие клавиши b: выбор режима возврата — робот выполнит навигацию обратно к исходной точке (начальному положению).

3.1 get_nav2_status_V2

На виртуальной машине путь к исходному коду программы: /home/yahboom/yahboomcar_ws/src/yahboom_nav2_bringup/yahboom_nav2_bringup/get_nav2_status_V2.py. Функция этой программы — получение статуса навигации и публикация/приём ряда топиков.

import rclpy
from rclpy.action import ActionClient
from geometry_msgs.msg import PoseStamped,Twist,PoseWithCovarianceStamped

Программа инициализируется и создаёт клиенты действий, публикаторов и подписчиков:

def __init__(self):
    super().__init__('navigation_client')
    #Создаём клиента действия; вызываемый сервис действия — /navigate_through_poses
    self._client = ActionClient(self, NavigateThroughPoses, '/navigate_through_poses')
    #Создаём подписчика на топик /back_orin; функция обратного вызова публикует целевое положение возврата к исходной точке
    self.sub_back_orin = self.create_subscription(Bool,"/back_orin",self.send_back_orinCallBack,1)
    #Создаём подписчика на топик /waypoints; функция обратного вызова публикует целевое положение, выбранное мышью
    self.get_waypoints = self.create_subscription(MarkerArray,"/waypoints",self.get_waypointsPoseCallBack,1)
    #Создаём подписчика на топик /No_found; функция обратного вызова изменяет значения некоторых переменных, когда после поворота машинный код не найден
    self.sub_no_found = self.create_subscription(Bool,"/No_found",self.get_FoundFlagCallBack,1)
    #Создаём подписчика на топик /grasp_done; функция обратного вызова изменяет статус некоторых переменных после того, как захват завершил захват машинного кода
    self.sub_grasp_done = self.create_subscription(Bool,"/grasp_done",self.get_GraspStatuCallBack,1)
    #Создаём подписчика на топик /cmd_vel_nav; функция обратного вызова изменяет значение переменной self.move_flag, если скорость навигации равна 0
    self.sub_cmd_vel = self.create_subscription(Twist,"/cmd_vel_nav",self.get_CurVelCallBack,1)
    #Создаём подписчика на топик /next_status; функция обратного вызова изменяет текущий статус в соответствии с сообщением топика
    self.sub_next_status = self.create_subscription(Int16,"/next_status",self.get_NextStatusCallBack,1)
    #Создаём публикатора для топика /beep; нижнеуровневый управляющий узел подписан на этот топик для управления звуковым сигнализатором
    self.pub_beep = self.create_publisher(UInt16, "beep", 10)
    #Создаём публикатора и публикуем топик /start_detect, чтобы включить программу обнаружения машинного кода
    self.pub_Detect = self.create_publisher(Bool, "/start_detect", 10)
    #Создаём публикатора с топиком /start_transport, который включает транспортировку и размещение по машинному коду
    self.pub_Transport = self.create_publisher(Bool, "/start_transport", 10)
    #Создаём публикатора, публикуем топик /back_to_orin — топик возврата к исходной точке
    self.pub_BackToOrin = self.create_publisher(Bool, "/back_to_orin", 10)
    #Создаём публикатора, публикуем топик /transport_done — топик завершения транспортировки
    self.pub_done = self.create_publisher(Bool, "/transport_done", 10)
    #Создаём подписчика на топик начального положения (положения исходной точки)
    self.sub_init_pose = self.create_subscription(PoseWithCovarianceStamped,"/initialpose",self.get_InitPoseCallBack,1)
    #Создаём объект координат целевой точки
    self.goal_pose = PoseStamped()
    #Создаём объект координат исходной точки
    self.orinal_pose = PoseStamped()
    self.goal_pose.header.frame_id = "map"
    self.orinal_pose.header.frame_id = "map"
    self.move_flag = False
    self.pub_rotate = True
    #Флаг завершения захвата; True означает, что захват завершён
    self.grasp_done = False
    #Определяем текущее состояние: возможны три значения — "Detect", "BackToOrint" и "Transbot"
    self.cur_status = "Detect"

def get_waypointsPoseCallBack(self,msg):

    #Получаем значения координат по индексу массива и присваиваем данные объекту координат целевой точки

send_goal:

def send_goal(self):
    #Создаём объект сообщения-цели (Goal) действия NavigateThroughPoses для отправки запроса навигации серверу действия NavigateThroughPoses Navigation2 (Action Server).
    goal_msg = NavigateThroughPoses.Goal()
    #Добавляем self.goal_pose в список goal_msg.poses, затем отправляем запрос навигации через send_goal_async, задавая функцию обратного вызова обратной связи (feedback_callback) и функцию обратного вызова ответа на цель (goal_response_callback) для обработки обновлений статуса и результатов во время навигации.
    goal_msg.poses.append(self.goal_pose)
    self._client.wait_for_server()

    self._client.send_goal_async(goal_msg,feedback_callback=self.feedback_callback).add_done_callback(self.goal_response_callback)

goal_response_callback:

def goal_response_callback(self, future):
    result = future.result()
    if not result.accepted:
        self.get_logger().error('Goal was rejected!')
        return
    self.get_logger().info('Goal accepted, waiting for result...')
    result_msg = result
    #print(result_msg)
    result.get_result_async().add_done_callback(self.result_callback)

feedback_callback:

def feedback_callback(self,feedback_msg):
    #Если оставшееся расстояние до точки навигации меньше 0.1 м, а значение self.move_flag равно false (скорость навигации равна 0), изменяем значение self.move_flag, чтобы облегчить следующую навигацию
    if feedback_msg.feedback.distance_remaining<0.10 and self.move_flag == False:
        self.move_flag = True

result_callback:

def result_callback(self, future):
    result_msg = future.result()
    print("the result_status is ",result_msg.status)
    #Если статус навигации равен 4, это означает, что целевая точка достигнута; тогда публикуем топик, управляющий звуковым сигнализатором робота для однократного сигнала, и в конце публикуем соответствующее сообщение в зависимости от текущего статуса
    if result_msg.status==4:
        self.Beep_Loop()
        self.move_flag = True
        self.pub_rotate = False
        print("Goal reached.")
        if self.cur_status == "Detect":
            detect = Bool()
            detect.data = True
            self.pub_Detect.publish(detect)
        elif self.cur_status == "Transbot":
            transport = Bool()
            transport.data = True
            self.pub_Transport.publish(transport)
            print("Arrival the target position,unload.")
        elif self.cur_status == "BackToOrin":
            print("Arrival the orin pose.")
            done = Bool()
            done.data = True
            self.pub_done.publish(done)
            self.cur_status = "Detect"

timer_callback:

def timer_callback(self):
    self.error = self.target_angle - self.turn_angle
    #Если значение self.compute_flag равно True, начинаем поворот
    if self.compute_flag == True:
        #Получаем текущий угол, self.rotate_angle
        self.get_angle()
        if self.rotate_angle<0:
            self.rotate_angle = 360 - abs(self.rotate_angle)
        #Вычисляем приращение угла поворота
        self.delta_angle = self.normalize_angle(self.rotate_angle - self.first_angle)
        #Вычисляем угол поворота
        self.turn_angle += self.delta_angle
        #Вычисляем значение ошибки
        self.error = self.target_angle - self.turn_angle
        print("self.error: ",self.error)
        self.first_angle = abs(self.rotate_angle)
        #Если ошибка меньше 10 градусов, поворот завершается
        if self.error <10:
            print("Rotation is done. ")
            self.compute_flag = False
            self.error = 0.0
            self.first_angle = 0.0
            self.turn_angle = 0.0
            rotate_done = Bool()
            rotate_done.data = True
            #Публикуем сообщение о завершении поворота
            self.pub_rotation.publish(rotate_done)

def get_angle(self):
    try:
        # Получаем преобразование между двумя системами координат
        transform = self.tf_buffer.lookup_transform('odom', 'base_footprint', rclpy.time.Time())
        quaternion = [0, 0, transform.transform.rotation.z, transform.transform.rotation.w]
        #Создаём объект вращения
        rotation = R.from_quat(quaternion)
        #Преобразуем в углы Эйлера
        euler_angles = rotation.as_euler('xyz', degrees=True)
        print("----------------------")
        #Извлекаем значение yaw — вращение вокруг оси z, здесь это угол поворота
        self.rotate_angle = euler_angles[2]
    except (tf2_ros.TransformException, KeyError) as e:
        self.get_logger().warn(f"Could not transform: {e}")

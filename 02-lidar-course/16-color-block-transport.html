Транспортировка цветных блоков

1. Описание содержания

В этом разделе объясняется, как объединить навигацию nav2, распознавание цветных блоков и трёхмерный захват манипулятором для реализации сложной функции транспортировки объектов.

В этом разделе команды вводятся в терминале. Какой терминал открывать, зависит от типа используемой материнской платы. В этом разделе в качестве примера используется Raspberry Pi 5. Для материнских плат Raspberry Pi и Jetson-Nano необходимо открыть терминал на хост-компьютере и ввести команду для входа в Docker-контейнер. После входа в контейнер вводите команды этого раздела уже внутри него. Инструкции по входу в Docker-контейнер с хост-компьютера см. в руководстве к изделию [Configuration and Operation Guide] — [Enter the Docker] (для пользователей Jetson-Nano и Raspberry Pi 5, см. соответствующий раздел).

Для плат Orin достаточно просто открыть терминал и ввести команды этого раздела.

2. Запуск программы

Виртуальная машина должна находиться в одной локальной сети с роботом, и значение ROS_DOMAIN_ID должно совпадать на обоих устройствах. Измените значение ROS_DOMAIN_ID в файле ~/.bashrc и обновите переменные окружения после изменения.

Введите следующую команду в терминале 1 робота, чтобы запустить программу камеры и решение кинематики манипулятора:

ros2 launch M3Pro_demo camera_arm_kin.launch.py

Введите следующую команду в терминале 2 робота, чтобы запустить программу слияния данных шасси и фильтрации объединённых данных лидара:

ros2 launch M3Pro_navigation base_bringup.launch.py

Введите следующую команду в терминале 3 робота, чтобы запустить программу захвата:

ros2 run M3Pro_demo grasp_transport

Введите следующую команду в терминале 4 робота, чтобы запустить программу распознавания цветных блоков:

ros2 run M3Pro_demo color_transport

Затем поместите цветной блок под камеру так, чтобы весь блок целиком попал в кадр, как показано ниже.

Введите команду в терминале 1 виртуальной машины, чтобы запустить отображение навигации в rviz.

ros2 launch slam_view slam_view.launch.py

Введите следующую команду в терминале 5 робота, чтобы запустить navigation2:

ros2 launch M3Pro_navigation navigation2.launch.py map_dir:=/root/M3Pro_ws/src/yahboom_mapping/maps/yahboom_map.yaml

Здесь /root/M3Pro_ws/src/yahboom_mapping/maps/yahboom_map.yaml замените на путь к файлу вашей собственной карты в формате yaml.

Введите следующую команду в терминале 2 виртуальной машины, чтобы запустить программу проверки статуса навигации:

ros2 run yahboom_nav2_bringup get_nav2_status_V2

После запуска в rviz на виртуальной машине с помощью инструмента [2D Pose Estimate] задайте роботу начальное положение, исходя из его фактического положения в пространстве и на карте. Убедитесь, что препятствия, отсканированные лидаром робота, совпадают с чёрными областями на карте, как показано на рисунке ниже.

Затем нажмите [Waypoint/Nav Through Poses Mode] в [Navigation2 navigation plug-in] и выберите его, как показано ниже.

Затем с помощью клавиш выберите, какой цветной блок захватить, или цвет калибровочного блока.

  • Нажмите R или r: сортировать красные блоки.
  • Нажмите G или g: сортировать зелёные блоки.
  • Нажмите B или b: сортировать синие блоки.
  • Нажмите Y или y: сортировать жёлтые блоки.
  • Нажмите C или c: откалибровать цвет выбранного блока.

После выбора цвета блока будет сформировано бинарное изображение, размещённое рядом с цветным изображением. Белая часть бинарного изображения — это выбранный цветной блок. Предположим, мы выбираем захват синего блока и нажимаем клавишу b, как показано ниже.

Если в этот момент синий цвет не распознаётся, необходимо нажать клавишу c, чтобы откалибровать значение HSV синего блока. После входа в режим калибровки с помощью мыши выделите область в центре синего блока и отпустите кнопку мыши, чтобы завершить калибровку, как показано на рисунке ниже.

После выбора цвета нажмите пробел, чтобы начать захват объекта. Если расстояние слишком большое или слишком маленькое, программа управляет перемещением шасси робота для корректировки расстояния. После того как манипулятор захватит объект, сработает звуковой сигнализатор, и робот переместится в положение для транспортировки. Наконец, робот повернётся на 90 градусов и войдёт в режим навигационной транспортировки.

Вход в режим навигационной транспортировки. В rviz с помощью [Nav2 Goal] задайте целевую точку. Робот построит путь и выполнит навигацию к этой точке. По достижении цели манипулятор опустит захват, чтобы положить цветной блок, а затем автономно вернётся навигацией в исходное положение для следующего распознавания цветного блока.

Функция обратного вызова callback для топика изображения:

def callback(self,color_frame,depth_frame):
    #Получаем данные топика цветного изображения и с помощью CvBridge преобразуем данные сообщения в данные изображения
    rgb_image = self.rgb_bridge.imgmsg_to_cv2(color_frame,'rgb8')
    rgb_image = cv2.cvtColor(rgb_image, cv2.COLOR_RGB2BGR)
    result_image = np.copy(rgb_image)
    #Получаем данные топика изображения глубины и с помощью CvBridge преобразуем данные сообщения в данные изображения
    depth_image = self.depth_bridge.imgmsg_to_cv2(depth_frame, encoding[1])
    frame = cv.resize(depth_image, (640, 480))
    depth_to_color_image = cv2.applyColorMap(cv2.convertScaleAbs(depth_image, alpha=1.0), cv2.COLORMAP_JET)
    depth_image_info = frame.astype(np.float32)
    key = cv2.waitKey(10)& 0xFF
    #Вызываем определённую функцию process для обработки нажатий клавиш и обработки изображения
    result_frame, binary = self.process(rgb_image,key)
    #Вызываем функцию потока для отображения изображения
    show_frame = threading.Thread(target=self.img_out, args=(result_frame,binary,))
    show_frame.start()
    show_frame.join()
    #При нажатии пробела изменяем значение self.pub_pos_flag
    if key == 32:
        self.pub_pos_flag = True
    if self.pub_pos_flag:
        #Если self.cx и self.cy не равны 0, значит цветной блок целевого цвета обнаружен. При этом радиус минимальной описанной окружности текущего цветного блока должен быть больше 30 — это отфильтровывает небольшие ошибочно распознанные области.
        if self.cx!=0 and self.cy!=0 and self.circle_r>30:
           #print("self.cx: ",self.cx)
           #print("self.cx: ",self.cy)
           cx = int(self.cx)
           cy = int(self.cy)
           dist = depth_image_info[int(cy),int(cx)]/1000

           pose = self.compute_heigh(cx,cy,dist)
            #Вычисляем расстояние между центром цветного блока и базовой системой координат base_link
           dist_detect = math.sqrt(pose[1] ** 2 + pose[0]** 2)
           dist_detect = dist_detect*1000
            #Если расстояние меньше 130 мм, оно считается недопустимым
           if dist_detect<130:
               print("Invalid dist.")
               self.valid_dist = False
           dist = 'dist: ' + str(dist_detect) + ' mm'
           print("dist: ",dist)
            #Если расстояние допустимо и выходит за пределы диапазона [215, 225], управляем шасси для корректировки расстояния
           if abs(dist_detect - 220.0)>10 and self.adjust_dist==True and self.valid_dist == True:
               self.move_dist(dist_detect)
           else:
               self.pubVel(0,0,0)
               self.adjust_dist = False
               cx = int(self.cx)
               cy = int(self.cy)
                #Вычисляем информацию о глубине для центральной точки цветного блока
               dist = depth_image_info[int(cy),int(cx)]/1000
           #print("dist: ",dist)
               if dist!=0:

                   vx = self.corners[0][0][0] - self.corners[1][0][0]
                   vy = self.corners[0][0][1] - self.corners[1][0][1]

                   self.pos_info_pub.publish(pos)

Лидар-охрана (Lidar Guard)

1. Описание содержания

В этом разделе описано, как программа объединяет управление шасси с объединёнными данными лидара для обнаружения в реальном времени ближайшего к роботу объекта и управления поворотом шасси для его отслеживания. Кроме того, если расстояние до объекта становится меньше порога срабатывания сигнализации, звуковой сигнализатор (buzzer) на роботе подаёт сигнал тревоги.

В этом разделе команды вводятся в терминале. Какой терминал открывать, зависит от типа используемой материнской платы. В качестве примера здесь используется Raspberry Pi 5. Для материнских плат Raspberry Pi и Jetson-Nano необходимо открыть терминал и ввести команды для входа в Docker-контейнер. После входа в контейнер вводите команды этого раздела уже внутри него. Инструкции по входу в Docker-контейнер см. в руководстве к изделию [Robot Configuration and Operation Guide] — [Entering the Docker] (для пользователей Jetson-Nano и Raspberry Pi 5, см. соответствующий раздел).

На материнской плате Orin достаточно просто открыть терминал и ввести команды этого раздела.

2. Запуск программы

Сначала откройте терминал и введите следующую команду, чтобы запустить программы слияния и фильтрации данных лидара.

ros2 launch yahboom_M3Pro_laser laser_driver.launch.py

Далее можно обратиться к разделу руководства к изделию [5. Chassis Control] — [2. Handle Control], чтобы запустить управление с геймпада для удобного управления роботом. Нажмите кнопку R2 на геймпаде, чтобы отменить и запустить режим отслеживания объекта лидаром. Если управление с геймпада не запущено, это не влияет на работу данной программы. Введите в терминале следующую команду, чтобы запустить программу отслеживания объекта лидаром:

ros2 run yahboom_M3Pro_laser laser_Warning

После запуска программы лидар сканирует ближайший объект в пределах диапазона обнаружения. При медленном перемещении объекта влево или вправо шасси поворачивается, отслеживая объект и направляя на него переднюю часть робота. Если расстояние между роботом и объектом становится меньше 0.55 метра, срабатывает встроенный звуковой сигнализатор.

Программа инициализируется и создаёт публикаторы (publishers) и подписчиков (subscribers):

def __init__(self,name):
    super().__init__(name)
    #Создаём подписчика на топик объединённых данных лидара
    self.sub_laser = self.create_subscription(LaserScan, "/scan", self.registerScan, 1)
    #Создаём подписчика на топик управления с геймпада
    self.sub_JoyState = self.create_subscription(Bool,'/JoyState', self.JoyStateCallback,1)
    #create a pub
    #Создаём публикатора для топика скорости
    self.pub_vel = self.create_publisher(Twist,'/cmd_vel',1)
    #Создаём публикатора для топика звукового сигнализатора
    self.pub_Buzzer = self.create_publisher(UInt16,'/beep',1)
    #declareparam
    self.declare_parameter("linear",0.5)
    self.linear = self.get_parameter('linear').get_parameter_value().double_value
    self.declare_parameter("angular",1.0)
    self.angular = self.get_parameter('angular').get_parameter_value().double_value
    # Угол обнаружения лидара
    self.declare_parameter("LaserAngle",45.0)
    self.LaserAngle = self.get_parameter('LaserAngle').get_parameter_value().double_value
    #Дистанция срабатывания сигнализации: звуковой сигнализатор включится, если расстояние меньше этого значения
    self.declare_parameter("ResponseDist",0.55)
    self.ResponseDist = self.get_parameter('ResponseDist').get_parameter_value().double_value
    #Флаг управления с геймпада. Значение True означает, что роботом управляет геймпад; чтобы включить управление с геймпада, нужно нажать кнопку R2 на геймпаде
    self.Joy_active = False
    #Создаём объект ПИД-регулятора угловой скорости
    self.ang_pid = SinglePID(3.0, 0.0, 5.0)

Функция обратного вызова registerScan для топика лидара:

def registerScan(self, scan_data):
    if not isinstance(scan_data, LaserScan): return
    ranges = np.array(scan_data.ranges)
    minDistList = []
    minDistIDList = []

    for i in range(len(ranges)):
        #Переводим радианы из данных топика лидара в градусы
        angle = (scan_data.angle_min + scan_data.angle_increment * i) * RAD2DEG
        #Если текущий угол находится в диапазоне обнаружения и расстояние на этом угле не равно 0
        if abs(angle) < self.LaserAngle and ranges[i] !=0.0 :
            #print("angle: ",angle)
            #Добавляем расстояние на этом угле в список минимальных расстояний
            minDistList.append(ranges[i])
            #Добавляем угол в список минимальных углов
            minDistIDList.append(angle)
    if len(minDistList) == 0: return
    # Находим минимальное значение в списке расстояний
    minDist = min(minDistList)
    #Находим соответствующий этому минимальному расстоянию угол
    minDistID = minDistIDList[minDistList.index(minDist)]
    print("minDistID: ",minDistID)
    #Если self.Joy_active равно True, публикуем скорость останова и выходим из этой функции обратного вызова
    if self.Joy_active :
        self.pub_vel.publish(Twist())
        return

    print("minDist: ",minDist)
    #Если расстояние до робота меньше дистанции срабатывания сигнализации
    if minDist <= self.ResponseDist and minDist!=0.0:
        b = UInt16()
        b.data = 1
        self.pub_Buzzer.publish(b)
    else:
        self.pub_Buzzer.publish(UInt16())
    velocity = Twist()
    print("minDistID: ",minDistID)
    #Рассчитываем угловую скорость
    ang_pid_compute = self.ang_pid.pid_compute(abs(minDistID) / 72, 0)
    #Если минимальный угол больше 0, значит объект находится слева от робота, поэтому робот поворачивает вправо
    if 0 < minDistID :
        velocity.angular.z = ang_pid_compute
    #Если минимальный угол меньше 0, значит объект находится справа от робота, поэтому робот поворачивает влево
    elif minDistID < 0 :
        velocity.angular.z = -ang_pid_compute
    print("orin_angular.z: ", velocity.angular.z)
    if abs(ang_pid_compute) < 0.5 : velocity.angular.z = 0.0
    velocity.angular.z = velocity.angular.z * 0.5
    print("angular.z: ", velocity.angular.z)
    #Публикуем топик управления скоростью
    self.pub_vel.publish(velocity)

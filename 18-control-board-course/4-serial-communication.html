Обмен данными по последовательному порту

1. Цель эксперимента

Использование последовательного порта на плата управления STM32 для изучения приёма и передачи данных.

2. Подключение оборудования

Как показано на рисунке ниже, чип последовательного порта CP2104 — встроенный компонент платы, поэтому дополнительные устройства не требуются. Подключите кабель Type-C между компьютером и портом USB Connect на плата управления STM32.

Если драйвер последовательного порта CP2104 не установлен, откройте браузер и перейдите по следующей ссылке, чтобы скачать, распаковать и установить его.

https://www.silabs.com/documents/public/software/CP210x_Windows_Drivers.zip

3. Анализ основного кода

Путь к исходному коду программы:

Board_Samples/STM32_Samples/Uart

В качестве примера рассмотрим последовательный порт 1. Вывод UART1_TXD порта 1 соответствует аппаратному выводу PA9, UART1_RXD — выводу PA10, скорость передачи установлена на 115200, 8 бит данных, 1 стоп-бит, без проверки чётности.

void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
     /* Prevent unused argument(s) compilation warning */
     UNUSED(huart);
     /* NOTE: This function should not be modified, when the callback is needed,
                 the HAL_UART_RxCpltCallback can be implemented in the user file
      */
     // Тестовая отправка данных. На практике данные не следует отправлять внутри прерывания

     HAL_UART_Transmit(&huart1, (uint8_t *)&RxTemp, 1, 0xFFFF);

     // Продолжить приём данных
     HAL_UART_Receive_IT(&huart1, (uint8_t *)&RxTemp, 1);
}

4. Компиляция, загрузка и прошивка firmware

Выберите проект для компиляции в панели управления файлами STM32CubeIDE и нажмите кнопку компиляции на панели инструментов, чтобы начать сборку.

Если ошибок и предупреждений нет, компиляция завершена.

Нажмите и удерживайте кнопку BOOT0, затем нажмите кнопку RESET для сброса, отпустите кнопку BOOT0, чтобы войти в режим прошивки через последовательный порт. Затем используйте инструмент прошивки через последовательный порт, чтобы записать firmware на плату.

Если у вас есть ST-LINK или J-Link, можно также использовать STM32CubeIDE для прошивки firmware одним нажатием — это более удобно и быстро.

5. Результаты эксперимента

Светодиод MCU_LED мигает каждые 200 миллисекунд.

Подключите плата управления к компьютеру через кабель Type-C, откройте программу-терминал последовательного порта (конкретные параметры показаны на рисунке ниже), и вы увидите, что в терминале выводится count:xx, а значение счётчика автоматически увеличивается на 1 раз в секунду.

Отправьте из терминала последовательного порта символьную строку hello, и плата автоматически вернёт обратно строку hello.

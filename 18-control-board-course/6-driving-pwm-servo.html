Управление ШИМ-сервоприводом

  • 1. Цель эксперимента
  • 2. Подключение оборудования
  • 3. Анализ основного кода
  • 4. Компиляция, загрузка и прошивка firmware
  • 5. Результаты эксперимента

1. Цель эксперимента

Использование ШИМ-выхода плата управления STM32 для изучения управления ШИМ-сервоприводом.

2. Подключение оборудования

Как показано на рисунке ниже, плата управления STM32 имеет встроенный интерфейс управления ШИМ-сервоприводом, однако сам ШИМ-сервопривод нужно подготовить и подключить дополнительно.

Подключите кабель Type-C к компьютеру и порту USB Connect на плата управления STM32.

Так как ток ШИМ-сервопривода относительно велик, при недостаточном питании подключите батарею.

Есть два порта для ШИМ-сервоприводов, S1 и S2, к обоим можно подключать ШИМ-сервоприводы.

Порядок подключения проводов сервопривода: коричневый провод — к GND, красный провод — к 5В, жёлтый провод — к S1/S2.

Под интерфейсом ШИМ-сервопривода есть переключатель напряжения. Значение по умолчанию — 5В. При необходимости можно переставить перемычку (jumper), чтобы переключиться на 6,8В. Если требуется использовать сервопривод на 6,8В, подключите батарею для питания.

3. Анализ основного кода

Путь к исходному коду программы:

Board_Samples/STM32_Samples/Pwm_Servo

Сервоприводы S1 и S2 привязаны к таймеру TIM12. Сервопривод S1 соответствует аппаратному выводу PB15 (TIM12, канал 2), сервопривод S2 — выводу PB14 (TIM12, канал 1).

Инициализируйте таймер TIM12 и настройте коэффициент деления частоты на 239, диапазон счёта — от 0 до 19999. Исходя из тактовой частоты таймера TIM12, равной 240 МГц, частота ШИМ рассчитывается как 240000000/(239+1)/(19999+1) = 50 Гц.

Инициализация ШИМ-сервопривода: запуск каналов 1 и 2 таймера TIM12 для вывода сигналов ШИМ, установка начального положения сервопривода на 90 градусов.

void PwmServo_Init(void)
{
        // Включить канал ШИМ
        HAL_TIM_PWM_Start(&htim12, TIM_CHANNEL_1);
        HAL_TIM_PWM_Start(&htim12, TIM_CHANNEL_2);

        // Установить начальный угол 90 градусов.
        PwmServo_Set_Angle(PWM_SERVO_ID_MAX, 90);
}

Преобразование входного угла сервопривода в значение импульса ШИМ.

static uint32_t Angle_To_Pulse(uint8_t angle)
{
        return (uint32_t)angle * 11 + 500;
}

Примечание: у разных сервоприводов угол при одинаковом коэффициенте заполнения может отличаться. Метод расчёта можно скорректировать с учётом фактических условий.

Для управления углом сервопривода можно различать управление по входному ID сервопривода, а затем преобразовывать значение угла в значение импульса ШИМ, тем самым выводя прямоугольные сигналы с разным коэффициентом заполнения для вращения сервопривода.

#define Servo_Set_Pulse_S1(value) TIM12->CCR2=value
#define Servo_Set_Pulse_S2(value) TIM12->CCR1=value

void PwmServo_Set_Angle(uint8_t id, uint8_t angle)
{
     uint16_t pulse = Angle_To_Pulse(angle);
     if (id == PWM_SERVO_ID_1)
     {
          Servo_Set_Pulse_S1(pulse);
          return;
     }
     if (id == PWM_SERVO_ID_2)
     {
          Servo_Set_Pulse_S2(pulse);
          return;
     }
     if (id == PWM_SERVO_ID_MAX)
     {
          Servo_Set_Pulse_S1(pulse);
          Servo_Set_Pulse_S2(pulse);
          return;
     }
}

Вызовите функцию PwmServo_Init в App_Handle для инициализации сервопривода, а затем меняйте угол сервопривода каждую 1 секунду в цикле, чтобы сервопривод качался вперёд-назад.

void App_Handle(void)
{
    int servo_count = 0;
    int servo_angle = 0;
    PwmServo_Init();
    while (1)
    {
         servo_count++;
         if (servo_count >= 100)
         {
              servo_count = 0;
              if (servo_angle == 0)
              {
                   servo_angle = 180;
              }
              else
              {
                   servo_angle = 0;
              }
              PwmServo_Set_Angle(PWM_SERVO_ID_MAX, servo_angle);
         }
         App_Led_Mcu_Handle();
         HAL_Delay(10);
    }
}

4. Компиляция, загрузка и прошивка firmware

Выберите проект для компиляции в панели управления файлами STM32CubeIDE и нажмите кнопку компиляции на панели инструментов, чтобы начать сборку.

Если ошибок и предупреждений нет, компиляция завершена.

Нажмите и удерживайте кнопку BOOT0, затем нажмите кнопку RESET для сброса, отпустите кнопку BOOT0, чтобы войти в режим прошивки через последовательный порт. Затем используйте инструмент прошивки через последовательный порт, чтобы записать firmware на плату.

Если у вас есть ST-LINK или J-Link, можно также использовать STM32CubeIDE для прошивки firmware одним нажатием — это более удобно и быстро.

5. Результаты эксперимента

Светодиод MCU_LED мигает каждые 200 миллисекунд.

Угол сервопривода изменяется каждую секунду, от 0 до 180, а затем от 180 до 0, и продолжает работать, тем самым реализуя функцию повторяющегося вращения сервопривода.

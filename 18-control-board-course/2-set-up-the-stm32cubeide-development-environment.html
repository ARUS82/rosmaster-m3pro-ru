1. Знакомство с STM32CubeIDE

STM32CubeIDE — это универсальный многоплатформенный инструмент разработки и продвинутая среда разработки на C/C++ с возможностями конфигурации периферии, генерации кода, компиляции и отладки для микроконтроллеров и микропроцессоров STM32. Среда построена на базе фреймворка Eclipse®/CDT™ и набора инструментов GCC для разработки, а также GDB для отладки. Она позволяет выбрать микропроцессор STM32, создать проект и сгенерировать код инициализации. Поддерживается графическая настройка тактирования и выводов STM32, а также основные платформы: Windows, Linux и Mac. Функциональность среды весьма мощная и практичная.

2. Загрузка установочного пакета

Откройте следующую ссылку в браузере на компьютере:

https://www.st.com/en/development-tools/stm32cubeide.html

Скачайте версию в соответствии с операционной системой компьютера. В качестве примера рассмотрим установку текущей последней версии (1.19.0) для Win10. Действия для других версий аналогичны.

Если у вас есть учётная запись на my.st.com, вы можете войти напрямую и скачать программное обеспечение. Если вы не хотите входить сейчас, просто укажите своё имя и адрес электронной почты в форме ниже, чтобы скачать программу.

Распакуйте скачанный файл, при этом путь распаковки не должен содержать символов на китайском языке (кириллицу и другие национальные символы также рекомендуется не использовать).

3. Начало установки

Дважды щёлкните, чтобы открыть установочный пакет. Затем следуйте указаниям мастера установки.

Путь установки можно изменить в соответствии с реальными потребностями. Убедитесь, что путь не содержит символов на китайском языке.

Выберите драйвер и нажмите Install.

Затем просто подождите завершения установки.

4. Создание нового проекта

  1. Дважды щёлкните по ярлыку на рабочем столе, чтобы открыть STM32CubeIDE. Необходимо выбрать рабочую область (workspace) и сохранить её по отдельному пути (без символов на китайском языке).

  1. Нажмите File → New → STM32 Project.

  1. Найдите и выберите чип STM32H743VGT6, затем нажмите Next в правом нижнем углу, чтобы перейти к следующему шагу.

  1. Введите название проекта. В качестве примера возьмём LED. Остальные параметры можно оставить по умолчанию.

  1. Нажмите Yes, и загрузится графическое содержимое.

5. Настройка выводов

  1. Сначала необходимо настроить отладочную информацию. В разделе Pinout & Configuration нажмите [Trace and Debug] → [Debug] и выберите [Serial Wire].

  1. Измените системную тактовую частоту STM32 и частоту внешнего кварцевого резонатора 25 МГц.

В Pinout & Configuration выберите [RCC] → [HSE] и укажите [Crystal/Ceramic Resonator]. HSE — это внешний тактовый сигнал, а LSE — внутренний. Использование внешнего тактового сигнала более стабильно и эффективно, чем внутреннего.

Перейдите на вкладку [Clock Configuration], установите основную частоту чипа 480 МГц и нажмите Enter для подтверждения.

  1. Добавьте настройку вывода LED_MCU. Согласно схеме назначения выводов, светодиод подключён к выводу PC13.

Настройте вывод PC13 в режим GPIO_Output. Для удобства измените Label на LED_MCU.

Затем нажмите Ctrl+S для сохранения, отметьте пункт Remember my decision и нажмите Yes. Это включит автоматическую генерацию кода при каждом сохранении.

6. Написание кода

  1. Поскольку код инициализации системы уже сгенерирован на предыдущем шаге графической настройки, нам нужно только добавить требуемую функциональность.

Найдите функцию main в файле main.c и добавьте код ниже while(1), чтобы управлять светодиодом. Это заставит светодиод мигать каждые 200 миллисекунд. Нажмите Ctrl+S, чтобы сохранить код.

Примечание: содержимое кода необходимо добавлять между метками USER CODE BEGIN и USER CODE END. В противном случае при следующей генерации кода графическим инструментом добавленный код будет перезаписан. Код, добавленный между USER CODE BEGIN и USER CODE END, не перезаписывается. Не пишите в этом разделе комментарии на китайском языке (или другом языке с не-ASCII символами), так как это может привести к появлению «кракозябр» (искажению кодировки).

7. Компиляция программы

  1. Добавьте функцию генерации HEX-файла.

Нажмите Project → Properties → C/C++ Build → Settings → MCU Post build outputs, затем отметьте пункт Convert to Intel Hex file (-O ihex), как показано на рисунке ниже.

  1. Нажмите на значок молотка на панели инструментов, чтобы начать компиляцию проекта.

Появится окно консоли STM32CubeIDE Console. Если вы видите 0 ошибок компиляции и 0 предупреждений, компиляция прошла успешно. Как показано на рисунке ниже, файл, сформированный проектом, называется LED.hex и сохраняется в папке Debug каталога проекта.
